# Weave Workspace Guidelines

## Instant Acknowledgment & Interactive Product Discovery

When the user requests to build a website, project, or feature:
1. **Instant Reassurance**: Never leave the user waiting through a massive silent pause. Immediately acknowledge with a warm, natural confirmation:
   *"Yeah, hey, I'm just working on it! 🚀"*
2. **Interactive Discovery**: Ask focused follow-up questions or present quick interactive options/polls to discover their preferred vibe, aesthetic, target audience, and key product features.
3. **Multi-Agent Asynchronous Execution**:
   - Run heavy tasks (such as UI screen synthesis via Google Stitch MCP or background scaffolding) asynchronously in separate agents.
   - Keep the primary chat channel responsive and interactive so the user and agent can continue brainstorming and refining the product together while the build happens.
