## 🛠️ Viewing the Screens

You can open any of the HTML files in `html/` directly in any web browser:

```bash
# Example: preview the 3-step setup and WhatsApp QR link screen
firefox designs/html/07_weave_3_step_setup_whatsapp_link.html
```

Or open the interactive design gallery:

```bash
firefox designs/index.html
```
